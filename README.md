# Práctica 1 - Machine Learning para Robótica e Inteligencia Artificial

## Estudiante

Cristian Zurita

## Descripción

Este proyecto desarrolla un pipeline reproducible de Machine Learning
utilizando un dataset real de navegación robótica.

Durante la práctica se implementarán técnicas de análisis exploratorio de datos,
preprocesamiento, aprendizaje supervisado, aprendizaje no supervisado,
reducción dimensional y evaluación del rendimiento de los modelos.

## Estructura del proyecto

- `data/raw/`: datos originales sin modificar.
- `data/processed/`: datos procesados y transformados.
- `notebooks/`: análisis exploratorio y experimentación.
- `src/`: código fuente reutilizable en Python.
- `reports/`: reportes y analisis de los resultados obtenidos al ejecutar codigo de 'src/'.
- `models/`: modelos de Machine Learning entrenados.
